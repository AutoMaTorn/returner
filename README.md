# Returner

Приложение для Windows и macOS: возвращает на iPhone приложения, которые исчезли из App Store,
но всё ещё выдаются вашему Apple ID. По USB, без джейлбрейка и переподписи — ставится оригинальный файл Apple.

## Скачать

Готовые сборки — на странице [Releases](../../releases/latest):

- **Windows 10/11 x64** — `returner-setup-<версия>-windows-x64.exe` (установщик) или `.zip` (без установки);
- **macOS** — `returner-<версия>-macos.dmg`.

Сборки не подписаны. Windows покажет «Неизвестный издатель» — нажмите «Подробнее» → «Выполнить в любом случае».
macOS: перетащите Returner в «Программы» и запускайте оттуда, не из окна `.dmg`. При первом запуске macOS откажется
открыть приложение — разрешите его в «Системных настройках → Конфиденциальность и безопасность» («Всё равно открыть»).
Если macOS спрашивает при каждом запуске, снимите с приложения пометку «скачано из интернета» одной командой в Терминале:
`xattr -dr com.apple.quarantine /Applications/Returner.app`.

## Как пользоваться

1. Установите Returner. На Windows нужен драйвер Apple — приложение «Apple Devices» из Microsoft Store или iTunes;
   если его нет, Returner предложит поставить.
2. Войдите в Apple ID. Пароль и код подтверждения уходят только в Apple.
3. Подключите iPhone кабелем, разблокируйте, нажмите «Доверять».
4. Выберите приложение в **Каталоге** или найдите в **Поиске** по названию, App Store ID или ссылке.
5. Нажмите «Установить на iPhone». Ход работы и итог видны в панели «установка» справа.

Скачанное остаётся в **Файлах**: его можно поставить снова без интернета и без входа в Apple ID.

Если новая версия не ставится на старую iOS — «Выбрать версию» и взять сборку постарше.
Если что-то пошло не так — «скопировать отчёт»: в нём нет почты, паролей и номеров устройств.

## Ограничения

- Скачать можно только то, что Apple выдаёт вашему аккаунту: то, что вы раньше скачивали, или бесплатное приложение,
  которое Apple ещё раздаёт. Если Apple отказывает — Returner показывает отказ и ничего не обходит.
- Каталог — это список известных приложений, а не обещание: доступность зависит от вашего аккаунта.
- Установка не гарантирует, что приложение запустится и что его сервис работает.
- Обновлений через App Store не будет — новую версию ставить через Returner.
- Используется неофициальный протокол App Store (через ipatool): Apple может его изменить. Формально это не
  соответствует условиям Apple.

## Приватность

Своего сервера нет. Сессия Apple ID, скачанные файлы, база и журнал лежат только на вашем компьютере.
Пароль не сохраняется; пароль, код и ключ хранилища передаются вложенной программе через stdin, а не в командной строке.

## Как устроено

Интерфейс на Flutter запускает две вложенные программы:

- **[ipatool](https://github.com/majd/ipatool)** (MIT, изменённая сборка) — вход в Apple ID и скачивание `.ipa`.
  Изменение лежит в `tools/patches/`: чтение учётных данных из stdin и отдельная папка сессии;
- **[go-ios](https://github.com/danielpaulus/go-ios)** (MIT) — список устройств и установка по USB.

Названия и значки приложений в каталоге принадлежат их владельцам и приведены только чтобы приложение можно было узнать.
Значков каталога в репозитории нет — они идут только в готовых сборках. Сборка из исходников берёт значки у Apple
или из скачанного файла, а если взять негде — показывает заглушку.

## Сборка из исходников

Нужны Flutter (stable), Git и Go. На Windows — ещё Visual Studio с C++, «Режим разработчика» и «Apple Devices»;
на macOS — Xcode.

```bash
flutter pub get
dart run tool/fetch_binaries.dart   # собирает ipatool с изменением, скачивает go-ios
flutter analyze
flutter test
flutter run -d windows              # или -d macos
```

Пакеты для распространения:

```bash
dart run tool/package_windows.dart  # установщик (нужен Inno Setup 6) и zip в build/dist/
tool/package_macos.sh               # .dmg в build/dist/, на Mac
```

Версии вложенных программ закреплены в `tools/versions.json`.
